# Security Policy

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately by email to the
project maintainer, or by using GitHub's private vulnerability reporting if it
is enabled for this repository.

Do not open a public issue for vulnerabilities that could expose users or their
projects to risk. Include the affected version, reproduction steps, expected
impact, and any relevant sample files or logs.

## Scope

Security reports for `owui-lint` may include issues in the CLI, language server,
VS Code extension, release artifacts, or update/install workflows.

## Supported Versions

Security fixes are provided for the latest released version.
